# Trademark & Branding Policy

"TEMM Nexus" is the name of the official project — the open-source,
self-hosted backend migration & control plane published in this
repository. The TEMM Nexus name, logo and other project branding
identify the official project and its community.

This policy describes how the name may be used. It is a plain-language
project policy, not legal advice, and it does not claim any registered
trademark status in any jurisdiction.

## What the open-source license covers

The GNU AGPL-3.0-only license in [LICENSE](LICENSE) covers the **source
code**. It does not automatically grant the right to present a project
as the official TEMM Nexus project.

## Allowed uses

- **Using TEMM Nexus** — running it, deploying it, building on it,
  talking and writing about it. Referencing the project by name
  ("we migrated from Supabase using TEMM Nexus", "our connector is
  compatible with TEMM Nexus") is fine, as long as the reference is
  accurate and does not suggest endorsement by the project.
- **Forks** — forking is allowed and encouraged under the terms of the
  software license. A fork may describe itself accurately as "based on
  TEMM Nexus" or "a fork of TEMM Nexus".
- **Integrations & connectors** — naming a connector/integration as
  compatible with TEMM Nexus is allowed when it actually is.

## Not allowed

- Presenting a fork, redistribution, or hosted service as the official
  TEMM Nexus project, or implying official endorsement, partnership or
  certification that does not exist.
- Using the TEMM Nexus branding in a way that misleads people about the
  origin of software or services.
- Using project branding in a manner that violates the license terms of
  the software itself.

If you are unsure whether a use is acceptable, ask before publishing —
open a discussion or an issue in this repository.
